# Zomato Customer Churn Analysis & Dashboard 🍕📊

An interactive Tableau dashboard built to identify customer churn.

## 🔍 Key Insights:
- **Billing Issues:** Associated with an extremely high churn rate (~96%).
- **Engagement:** Customers with low order frequency (0–2 orders/month) exhibit the highest risk of churning.
- **Delivery Ratings:** Churned customers reported noticeably lower average delivery ratings (3.40) compared to retained users (3.86).
